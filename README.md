# sloffer-frontend

React web UI for **Sloffer**: shows matched job listings with per-job status and filtering. Right now it's one page that shows the [backend](https://github.com/revazza/sloffer-backend)'s health.

## Quick start

```bash
npm ci
npm run dev    # http://localhost:5173 (start the backend API first)
npm test
```

See `CLAUDE.md` for all commands and conventions. Work arrives as ClickUp tasks (`Agent = Frontend`) via [sloffer-watcher](https://github.com/revazza/sloffer-watcher).
